# Knock

A neighbourhood board for small favours. One self-contained file: `index.html` (HTML, CSS and JS together). No build step.

## Run locally
Double-click `index.html` to open it in your browser.

## Put it on GitHub
```
cd knock
git init
git add .
git commit -m "Initial commit: Knock"
git branch -M main
git remote add origin https://github.com/<your-username>/knock.git
git push -u origin main
```
Create the empty `knock` repository on github.com first. For a live link, open Settings, then Pages, and choose the `main` branch and `/ (root)`.
